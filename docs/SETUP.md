# HeriTrace setup
1. Extract ZIP.
2. Open folder in VS Code.
3. Run `flutter pub get`.
4. Create a Firebase project.
5. Enable Email/Password in Authentication.
6. Create Firestore Database and Storage.
7. Install FlutterFire CLI and run `flutterfire configure`.
8. Run `flutter run -d chrome` or `flutter run`.
9. Backend: `cd backend`, create venv, `pip install -r requirements.txt`, then `uvicorn main:app --reload`.
