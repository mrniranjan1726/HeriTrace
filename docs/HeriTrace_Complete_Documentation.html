1. Executive Summary & Problem Solved

India represents one of the largest craft traditions in the world with over 7 million master craftspeople. However, intermediaries pocket 50%–80% of retail value, rural artisans face severe digital literacy barriers, and machine replicas flood the market.

🎙️ Voice-First AI

Allows low-literacy rural artisans to speak in regional languages to auto-generate full e-commerce catalogs.

📸 Computer Vision Studio

Transforms cluttered workshop photos into professional studio-lit e-commerce product mockups.

⚖️ Living Wage Guarantee

Mathematical formula guaranteeing artisans retain 70%–85% direct margin with zero middlemen markup.

2. High-Level System Architecture

HeriTrace utilizes a Hybrid 3-Tier Reactive Architecture:

1. CLIENT TIER (Flutter / Dart)
• Cross-platform compilation to Native Android APK, iOS IPA, and Responsive Web
• Native Speech-to-Text integration via OS audio pipelines
• State management using Provider, StreamBuilders, and ValueNotifiers for 60 FPS scrolling
2. CLOUD INFRASTRUCTURE (Google Firebase BaaS)
• Firebase Authentication: Role-Based Access Control (Artisan vs. Customer vs. Admin)
• Cloud Firestore: Real-time NoSQL streaming via WebSockets with Collection Groups
• Firebase Storage: Secure cloud buckets for high-res craft photography & GI proofs
• Firestore Security Rules: Server-side validation enforcing atomic auction bidding rules
3. AI & PAYMENT MICROSERVICE (FastAPI on Render)
• Computer Vision: Pillow image pipeline (EXIF orientation, background cleanup, contrast)
• Multilingual NLP: Regional transcript translation into English, Hindi, Odia, Bengali
• Living Wage Pricing: Material cost and labor formula ensuring artisan prosperity
• Razorpay Gateway: Order creation and cryptographic HMAC-SHA256 signature verification

3. Key Technical Modules

A. Dual-Platform Speech-to-Text Pipeline

Android 11+ (API 30+) blocks speech recognition discovery unless explicitly declared. HeriTrace configures package visibility with android.speech.RecognitionService and runtime microphone permissions on Android, while providing Apple Speech Framework declarations in iOS Info.plist. Available for customer voice search and artisan oral storytelling.

B. Live Synchronized Auction House

Rare masterworks are auctioned in real time. Backed by Cloud Firestore WebSocket subscriptions, bids update in sub-second latency across all clients with anti-sniping countdown timers and atomic security rules preventing concurrent bid overwriting.

C. 7-Day Return, Replacement & Exchange Suite

Complete reverse logistics lifecycle: customer selection (return, exchange, replace), reason logging, doorstep pickup address confirmation, real-time alert dispatch to artisan atelier portal, single-tap artisan authorization, and automatic refund/dispatch settlement.
