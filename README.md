# HeriTrace — Real MVP Foundation
AI-powered digital business manager and B2B marketplace for traditional artisans.
Supports Flutter Android + Web and is Firebase-ready.

## Setup
flutter pub get
dart pub global activate flutterfire_cli
flutterfire configure
flutter run -d chrome

Configure Firebase Authentication, Firestore and Storage in the Firebase Console.
The FastAPI endpoints are provider-neutral foundations; connect your chosen production AI provider/model before deployment.
